# 📝 Flask To-Do List Uygulaması

Bu proje, Flask kullanılarak geliştirilmiş basit bir **To-Do List (Yapılacaklar Listesi)** web uygulamasıdır.  
Kullanıcı yeni görev ekleyebilir, görevleri tamamlandı olarak işaretleyebilir ve silebilir.

---

## 🚀 Özellikler
- Yeni görev ekleme  
- Görevleri tamamlandı / tamamlanmadı olarak işaretleme  
- Görev silme  
- Sayfa yenilendiğinde görev listesini görüntüleme  
- Minimal ve anlaşılır Flask yapısı

---
